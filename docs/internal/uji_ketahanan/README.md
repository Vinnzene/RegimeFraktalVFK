# Uji Ketahanan Metode (internal, bukan untuk naskah)

Tangkapan layar halaman `/uji-ketahanan` (walk-forward, sensitivitas, Monte Carlo,
pembanding ADX/Choppiness). Hasil ini **tidak dipakai di naskah skripsi**; angka
naskah tetap dari `ml/artifacts/updated_eval_summary.json` (halaman Hasil Uji Identifikasi).

Halaman di aplikasi terkunci per akun: pengguna meminta akses, pemilik menyetujui
di `/admin/akses?fitur=robustness`. Saklar `UJI_KETAHANAN_TERBUKA=1` di
`backend/.env` membuka halaman untuk semua akun.
